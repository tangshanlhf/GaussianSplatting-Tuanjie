# GaussianSplatting 团结适配版（独立副本）

UnityGaussianSplatting (aras-p, v1.1.1) 的 Tuanjie 适配副本。
URP 渲染特性为双路径：Unity 6 走 RenderGraph；团结（Unity 2022.3 基座）走传统 ScriptableRenderPass 路径（团结的 RenderGraph 接口为 internal，第三方包无法实现）。

## 在其他项目中使用

### 方式一：file: 本地引用（推荐）

在目标项目的 `Packages/manifest.json` 的 `dependencies` 中添加：

```json
"org.nesnausk.gaussian-splatting": "file:C:/Users/tangs/Desktop/团结高斯泼溅插件/GaussianSplatting-Tuanjie"
```

### 方式二：嵌入项目

把本文件夹整体复制到目标项目的 `Packages/` 目录下即可。
注意连同所有 `.meta` 文件一起复制（脚本 GUID 依赖它们），建议用文件夹复制而不是挑选文件。

## 配置清单（URP 项目）

1. `burst` / `collections` / `mathematics` 依赖会从 packages.tuanjie.cn 自动解析，无需手动安装
2. URP Renderer 资产（如 `xxx_ForwardRenderer`）→ **Add Renderer Feature → GaussianSplatURPFeature**（不加则没有合成效果）
3. 保持 **RenderGraph 关闭**（团结默认即关闭）
4. 场景中挂 `GaussianSplatRenderer` 组件并指定 splat 资产
   （.ply / .splat / .spz 文件右键 → Create → Gaussian Splat Asset 导入）

## 注意事项

- 同一项目**不要**同时引用本副本和 `UnityGaussianSplatting-main\package`（包名相同会冲突）
- 内置渲染管线（非 URP）项目无需 Renderer Feature，自动走 Camera.onPreCull 路径
- 真 Unity 6 项目同样可用（RenderGraph 分支已保留）
- 本副本与 `UnityGaussianSplatting-main\package`（示例项目 GaussianExample-URP 正在引用的那份）内容一致；之后如果改了其中一份，另一份需要手动同步
